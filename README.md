# Cross-Sectional Equity Signals: An Honest Backtest

A small, reproducible study of three classic cross-sectional equity signals on
US large caps, built to answer one question honestly: **do these signals still
work out of sample, after realistic costs and execution delay?**

The emphasis is on methodology (no look-ahead, a held-out test period, costs,
and a null test on random data) rather than on finding a high Sharpe.

## Signals

| Signal | Definition | Hypothesis |
|---|---|---|
| `momentum_12_1` | Return from t-252 to t-21 trading days | Past 12-month winners keep outperforming; skipping the last month avoids short-term reversal |
| `reversal_5d` | Negative of last 5-day return | Short-term overreaction partially reverses |
| `low_vol_60d` | Negative 60-day realised volatility | Low-risk stocks earn better risk-adjusted returns than theory predicts |

Each day, every signal is converted into a **dollar-neutral long-short
portfolio**: rank stocks cross-sectionally, demean the ranks, and scale to
gross exposure 1 (`src/backtest.py::to_weights`).

## Methodology

- **No look-ahead.** A signal at date t uses closes up to t only. Weights are
  traded at the *next* close (`delay=1`) and first earn the return from t+1 to
  t+2, so I never assume I can trade at the same price used to compute the signal.
- **Transaction costs.** 5 bps per unit of one-way turnover by default, with a
  sensitivity grid from 0 to 20 bps.
- **Train/test split.** 2011 to 2018 is used for analysis and for fitting the
  combination weights. 2019 onward is touched once, for evaluation only.
- **Out-of-sample decay.** Reported as test Sharpe minus train Sharpe per signal.
- **Signal decay by horizon.** Mean daily rank IC (Spearman correlation between
  the signal and forward returns) at 1, 5, 10, 21 and 63 days.
- **Combination.** Signals are weighted by train-period Sharpe (floored at 0)
  and the blend is evaluated on the test period.
- **Null test.** `python run.py --synthetic` runs the identical pipeline on
  zero-drift random walks, where no signal can have an edge. Across 80 random
  seeds the mean gross Sharpe of momentum was 0.007 (s.e. 0.03), which supports
  the claim that the code has no look-ahead bias. While building this I found
  that log-normal random walks give high-volatility assets a +σ²/2 arithmetic
  drift, which created a fake (negative) low-volatility "signal". The synthetic
  generator now compounds simple returns so the null is truly zero.

## Limitations

- **Survivorship bias.** The universe is today's large caps that have existed
  since 2010, chosen with hindsight. A proper study would use point-in-time
  index membership, including firms that were later delisted.
- **Small universe** (~60 stocks), so cross-sectional signals are noisy.
- **Flat cost model**; no market impact, borrow costs, or shorting constraints.
- **No risk model**; portfolios are not neutralised to sector or market beta.
- Three signals tested, so some multiple-testing caution applies to any one result.

## Run it

```bash
pip install -r requirements.txt
python run.py                # downloads data once (cached in data/), writes results/
python run.py --synthetic    # null test on random data, no internet needed
pytest -q                    # look-ahead, cost and portfolio-construction tests
```

Options: `--split 2019-01-01 --cost-bps 5 --delay 1 --start 2010-01-01 --end 2025-12-31`

## Layout

src/signals.py    signal definitions
